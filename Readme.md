#THE COZY CORNER

A web blog app.

This website features include -
1. Modern Blog Editor using Editor JS.
2. Google Authentication for Users
3. Dynamic Blog Pages on dynamic URLs.
4. Search Page for Searching Blogs & Users.
5. Dedicated Users Profile with their social links and written blogs.
6. A dedicated dashboard to manage blogs, either published or draft.
7. Blog Post Analytics, editable and deletable.
8. Like interaction on Blogs with a feature to comment on the blog.
9. Reply to comments. ( A nested Comment System )
10. Every interaction on the site is stored as a notification for its respective users.
11. Recent notification highlights separating them from old notifications.
12. Edit profile option to update social links, bio, and username
13. Also user can change the login password from settings.
14. It's mobile responsive with modern design + fade-in page animation.
And much more.
